# engineer-mode

Small TypeScript projects I write by hand to keep the basics fresh.

No framework. No build tooling beyond `tsc`. Just HTML, the DOM, and TypeScript.

I forget this stuff when I am not using it, so this is where I come back and look it up.

## Projects

| # | Project | What it covers |
|---|---------|----------------|
| 01 | [Workout Timer](01-workout-timer) | DOM lookup, events, a single piece of state, `setInterval` / `clearInterval`, guarding against double starts, formatting seconds as `MM:SS` |
| 02 | [Todo App](02-todo) | `input.value`, arrays of objects, `type`, `push` / `filter` / `map` / `reduce`, building DOM nodes, checkboxes, removing nodes, `localStorage` with `JSON.stringify` / `JSON.parse` |

## Running one

```
cd 02-todo
npm install
npx tsc --watch
```

Then open `index.html` in a browser.

`main.js` is generated by `tsc` and is not tracked. `main.ts` is the source.
